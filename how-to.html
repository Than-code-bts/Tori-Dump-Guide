A practical guide to smarter file management, organization, and AI-powered retrieval.

What is Tori Dump?

Tori Dump is a core feature of the Tori Workspace that automates file management.

Automated File Management

Tori Dump organizes, routes, and indexes uploaded files and stores them in project directories.

AI-Powered Retrieval

Tori Dump enables efficient storage and AI-powered retrieval of files.

Why Use Tori Dump?

Traditional file storage can make documents difficult to locate when filenames are vague and metadata is overlooked.

Better File Organization

Uploaded files can be organized and routed into project directories.

Smarter Search

Tori Dump uses metadata and keyword matching to improve file retrieval.

Faster Retrieval

AI-powered query parsing supports contextual search and direct record retrieval.

Before You Upload: Name Your Files Properly

Descriptive filenames help Tori Dump identify useful search tokens and improve retrieval.

Avoid Vague Filenames

receipt.pdf
report.xlsx
tax_v2.pdf

Generic filenames provide fewer useful keywords for searching and indexing.

Use Specific, Descriptive Names

tax_and_compliance_q3_2026_BIR_VAT_Return_Filing_Receipt.pdf

Include meaningful keywords such as the subject, period, year, agency, document type, or other useful identifiers.

Golden Rule: Match File Names to Folder Names

Matching meaningful terms in the filename with the target folder can support automated routing.

Folder:
Tax_and_Compliance
File:
tax_and_compliance_q3_2026_BIR_VAT_Return_Filing_Receipt.pdf

How to Use Tori Dump

Follow these four steps to organize, upload, and retrieve files efficiently.

01

Prepare Your Files

Use clear and descriptive file names before uploading your documents. Include important keywords such as the document type, period, year, office, or transaction.

Example
❌ receipt.pdf
✓ tax_and_compliance_q3_2026_BIR_VAT_Return_Filing_Receipt.pdf
02

Set Up Your Workspace

Use your Tori Workspace and its project directories to provide the appropriate context for your files. This helps Tori understand where files belong.

Why this matters

Tori uses file names and workspace context to support automated file routing.

03

Upload Your Files

Drag and drop your files into Tori Dump. Batch uploading triggers the active ingestion process, allowing uploaded files to be organized and indexed.

Automation

Tori Dump helps reduce manual file organization by automatically routing files to appropriate project directories.

04

Search and Retrieve

Search for documents using meaningful keywords or contextual queries. Tori's retrieval system uses metadata and fuzzy matching to help locate relevant files.

AI-powered retrieval

Even when a search contains short names or minor typing errors, fuzzy token matching can help identify the relevant file.

How Tori Dump Works

Tori Dump combines automated file organization, metadata extraction, and AI-powered retrieval to make files easier to manage and find.

01

Automated Organization

Tori Dump organizes and routes uploaded files into project directories based on file names and workspace context.

02

Metadata Extraction

The system extracts useful information such as author, title, and timestamps and uses this information as part of the file's metadata.

03

AI-Powered Retrieval

Tori Dump uses fuzzy token matching to help identify relevant files, even when a search contains short names or minor typing errors.
