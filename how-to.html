Before You Upload

Name your files properly

Descriptive filenames give Tori useful search tokens and help automated organization.

Avoid vague filenames

receipt.pdf
report.xlsx
tax_v2.pdf

Generic filenames provide fewer useful keywords for searching and indexing.

Use specific filenames

tax_and_compliance_q3_2026_BIR_VAT_Return_Filing_Receipt.pdf

Useful filenames contain high-signal keywords such as the topic, period, year, agency, document type, and purpose.

Golden Rule 1: Be Specific & Descriptive

Include meaningful terms that describe what the file contains.

Golden Rule 2: Match File Tokens to Folder Name

Using words that match the target folder can help Tori route the file to the appropriate directory.

Example

If the target folder is Tax_and_Compliance, a filename containing matching terms such as tax_and_compliance can help Tori identify the appropriate destination.

Quick Tips

Get better results from Tori Dump

A few simple practices can make files easier to organize and retrieve.

  • Use specific and descriptive filenames.
  • Include useful keywords such as project, period, year, agency, and document type.
  • Match important filename tokens with relevant folder names when appropriate.
  • Use contextual search terms rather than relying only on exact filenames.
  • Do not worry if a search contains a typo; fuzzy matching can help identify relevant files.
  • Keep project information organized so files remain easier to retrieve.
